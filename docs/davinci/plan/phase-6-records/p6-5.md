# P6-5 — ExprRef validation report

The [validation report](../exprref-validation.md) records the second expression
implementation's capability, span, ABI, projection and checker findings.
Each finding has a fixed PR reference with merged/pending status, or a deferred
producer, matrix or review requirement with its rationale.

The report is delivered by
[PR #6795](https://github.com/ubugeeei-prod/vize/pull/6795). Its accepted fixes
retain the original ABI and compile/run actual historical SDK components.
P6-4b's automatic typed producer, declaration/import producer, full projection
matrix and maintainer acceptance remain open. The phase exit still requires
those validations.
